Python Programming – 5 Modules

About This Repository

This repository contains Python programs completed as part of my academic coursework. It includes basic Python concepts, problem-solving programs, data structures, file handling, and mini-projects across five modules.

Module 1 – Python Basics

Programs based on basic calculations and mathematical operations.

- "Lab_1.1,py" – Write and execute a basic program
- "Lab_1.2.py" – Programs using variable, operators and input/output
- "Lab_1.3.py" – simple calculator and area calculation programs.
- "Lab_1.4.py" – unit convertor or bill generator.

Module 2 – Control Statements and Loops

Programs based on loops, conditions, and number operations.

- "Lab_2.1.py" – Number guessing game
- "Lab_2.2.py" – Prime number program
- "Lab_2.2_1.py" – Calculates the factorial of a number.
- "Lab_2.3.py" – Fibonacci series using recursion.
- "Lab_2.4.py" – OTP generator.

Module 3 – Functions and Data Structures

Programs based on functions, lists, dictionaries, and data management.

- "Lab_3.1.py" – Manages contact information.
- "Lab_3.2.py" – Student grading system
- "Lab_3.3.py" – Frequency counter using dictionaries
- "Lab_3.4.py" – Attendance tracker or sales data analyser

Module 4 – File Handling and Data Processing

Programs based on files, CSV, JSON, and data management.

- "Lab_4.1.py" – Reads and processes log files.
- "Lab_4.2.py" – Manages student data.
- "Lab_4.3.py" – Manages payroll information using CSV files.
- "Lab_4.4.py" – Analyzes log files using JSON.

Module 5 – Python Mini Projects

Practical projects applying Python programming concepts.
